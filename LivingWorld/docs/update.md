# обновление 0.6.0-alpha — world qol & diagnostics

обновление не меняет основные правила поведения npc. оно делает уже существующую симуляцию удобнее для наблюдения, диагностики и дальнейшей разработки.

## поселения

- завершённые дома автоматически объединяются в поселения по расстоянию;
- каждому поселению детерминированно назначается имя из seed мира и стабильного id старейшего дома;
- вычисляются центр и границы поселения;
- житель с домом относится к поселению своего дома;
- житель без дома может относиться только к одному ближайшему поселению;
- для поселения считаются жители, семьи, дома, текущие стройки, локальный запас еды и основные специализации;
- отдельного village ai или новых целей npc не добавлено.

## интерфейс и навигация

- интерфейс переработан: отдельная навигационная панель слева, инспектор справа и компактная панель слоёв карты;
- добавлен поиск жителей по имени с быстрым переходом камерой;
- добавлен список поселений с переходом к выбранному поселению;
- добавлена отдельная вкладка поселения;
- обновлена визуальная тема: тёмная зелёно-графитовая основа, тёплые акценты, более выраженные состояния кнопок и панелей;
- новая форма создания мира сохраняет прежнюю механику генерации.

## слои карты

добавлены read-only overlay-режимы:

- границы и названия поселений;
- интенсивность троп;
- плодородие;
- комнаты.

`F3` циклически переключает слой. `F2` по-прежнему показывает маршрут и память выбранного жителя.

## diagnostics

- показано количество активных планов и их средняя длина;
- показано общее число неудач планирования и активных reservations;
- показаны количества жителей, предметов, растений, строек и огней;
- профили систем сортируются по средней стоимости;
- сохранены FPS, фактические ticks/sec, LOD, число видимых чанков и объектов.

## сохранения

- добавлены три save-слота;
- слот 1 продолжает использовать `world.save.json`, поэтому существующее сохранение остаётся совместимым;
- слоты 2 и 3 используют отдельные файлы;
- формат `WorldSnapshot` не менялся и миграция сохранений не требуется.

## технические изменения

- добавлен автоматический GitHub Actions workflow;
- CI выполняет structural checks, restore, Release build, regression tests, суточный headless smoke, недельный прогон дефолтного мира и запуск основной Godot-сцены через Godot 4.7.1 .NET;
- добавлен файл `VERSION` как единый номер версии;
- structural checks проверяют соответствие `VERSION`, `project.godot` и README;
- render snapshot расширен данными поселений, комнат, имён и текущих действий жителей без выдачи UI mutable-компонентов симуляции;
- добавлены regression tests для кластеризации поселений, стабильности имён, уникальной принадлежности жителей, render snapshot и независимых save-слотов.
