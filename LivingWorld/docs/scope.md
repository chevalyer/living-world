# сопоставление с планом

«реализовано» ниже означает наличие конкретной логики в исходниках. сборка, 54 регрессионные проверки и запуск godot без окна подтверждены; визуальная проверка в оконном режиме ещё не выполнена. результаты и границы проверок — в [validation.md](validation.md).

| этап | реализация | границы текущей версии |
| --- | --- | --- |
| 1. фундамент | реестр, компоненты, часы, события, rng, definitions | простое типизированное хранилище |
| 2. карта | клетки, чанки, проходимость, камера, рисование | конечная квадратная карта |
| 3. генерация | высоты, геология, дренаж, море, реки, озера, климат, биомы | гидрология при создании мира |
| 4. природа | деревья, кусты, трава, цветы, руда, рост и расселение | животные не входят в эту версию |
| 5. предметы | материалы, масса, объем, прочность, качество, владение | базовые свойства без подробной химии |
| 6. npc | имя, пол, дата рождения, тело, внешность, движение | пиксельная условная внешность |
| 7. физиология | голод, вода, сон, здоровье, температура | игровая модель |
| 8. одежда | слоты, покрытие, материал, износ, намокание | базовое взаимодействие слоев |
| 9. действия | отдельные файлы и общий исполнитель | ограничения повторно проверяются перед эффектом |
| 10. знания | восприятие, стены, память, уверенность, обмен наблюдениями | зрение клеточное |
| 11. utility | срочность нужд, характер, стоимость, риск, объяснения | коэффициенты требуют баланса |
| 12. планирование | поиск по предусловиям и эффектам, цепочки действий | глубина и вычислительный бюджет ограничены |
| 13. производство | добыча, физические предметы, рецепты и операции | многостадийные мастерские пока не реализованы |
| 14. строительство | детали здания, ресурсы, комнаты и общий склад | готовые чертежи 5 × 5; без мебели |
| 15. сезоны | календарь, климатическая волна, погода, снег, лед | локальные погодные фронты не реализованы |
| 16. отношения | общение, подарки, обмен, обучение, ресурсные конфликты | без сложной репутации и переговоров |
| 17. семьи | взрослое партнерство, беременность, рождение, уход | базовые правила выбора и условий семьи |
| 18. поколения | взросление, обучение, родословная, смерть | многолетняя устойчивость не измерена |
| 19. дороги | трафик, вытаптывание, восстановление, влияние на a* | нет отдельного строительства мощеных дорог |
| 20. общество | помощь в стройке, склад, излишки, индивидуальные оценки обмена, специализации по навыкам | государство, профессии с глубокими политиками и общественное планирование — дальнейшее развитие |

полноценный мир из всего исходного видения потребует дальнейших итераций. особые следующие задачи: расширить производство и источники материалов; настроить долгосрочное снабжение; развить уход за детьми и совместные решения семьи; измерить большие поселения; добавить более сложную экономику, животных и медицину.
